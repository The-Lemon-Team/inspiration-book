# Архитектура тегов

## Концепция

«Узнал», «Вспомнил», «Сделать» — **не жёсткие категории**, а **стартовые теги**.
Пользователь может создавать свои: `lo-fi`, `музыка`, `книги`, `программирование` и т.д.

## Формат сообщения в чате

Любая строка `Тег:` открывает блок, пункты `- ...` становятся записями:

```
Узнал:
 - Как варить суп

lo-fi:
 - Jazz-hop плейлист

программирование:
 - Изучить Prisma adapters
```

Если тег ещё не существует — он **создаётся автоматически** при отправке сообщения.

## Backend

- Модель `Tag`: `name`, `slug`, `color`, `isDefault`, `userId`
- При регистрации создаются 3 базовых тега
- API: `GET/POST/PATCH/DELETE /tags`
- Записи (`Entry`) ссылаются на `tagId`
- Фильтры: `tagId`, `visibility` (public/private)

## Frontend

- **Группы** (`/tags`) — управление тегами, bento-карточки из прототипа
- **Чат** — structured textarea, любые теги в заголовках
- **Лента / Борд** — фильтры по тегам (горизонтальные chips)
- **Mobile-first** UI из `prototypes/`, desktop от 768px (верхнее меню вместо bottom nav)

## Прототипы

HTML-макеты в `prototypes/` — референс для mobile UI.
Design tokens: `prototypes/personal_chronicle/DESIGN.md` → `frontend/src/styles/tokens.css`
