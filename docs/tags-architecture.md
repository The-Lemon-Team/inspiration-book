# Архитектура тегов и типов контента

## Формат сообщения

Сообщения — **обычный текст** и при необходимости **блоки контента** (музыка, видео, ссылка, картинка). Специального шаблона вроде `Узнал:` + список пунктов нет.

Примеры:

```
Сегодня хороший день #vibe

[music:card]https://www.youtube.com/watch?v=…[/music]
tags: #lofi, #work
```

## Две разные сущности

| | **Тип контента** | **Хештег (тег)** |
|---|---|---|
| Примеры | Музыка, YouTube-видео, дизайн | `#vibe`, `#result`, `#resume` |
| Откуда | Блоки сообщения | `#слово` в тексте, `extraTags` на music-блоке |

## Хештеги

- Упоминаются в тексте или в поле хештегов music-блока
- При отправке создаётся `Tag` (если ещё нет) и `Entry` для индексации
- Страница **Теги** (`/tags`) — статистика по хештегам

## Типы контента

- Определяются по блокам: `music` → Музыка, `youtube` → Видео
- Отображаются в карточке сообщения и в сводке чата
- **Не** выводятся из имён тегов

## Backend

- `Tag` + `Entry` — только для хештегов
- Сообщение без хештегов может существовать без записей `Entry`
- API: `GET/POST/PATCH/DELETE /tags`, `GET /tags/stats`
